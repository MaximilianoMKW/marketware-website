# Marketware Website Internal Pages Expansion - Agent Instructions

## Context

The Marketware homepage is already visually and strategically strong.  
The next priority is to turn the internal pages into credible, polished pages that feel ready for enterprise prospects.

The website positions Marketware as:

- A premium Dynatrace specialist consultancy
- Trusted in Portugal and Iberia
- Ready for international growth
- Strong in observability, digital experience, automation, and operational resilience
- Experienced with enterprise sectors such as banking, energy, insurance, and critical digital services

The current gaps are mainly in:

- `/case-studies`
- `/insights`
- `/contact`
- `/about`
- `/services`
- `/industries`

The Agent should expand these pages while maintaining:

- Clean React + Vite + TypeScript implementation
- Reusable components
- Data-driven content
- Modern responsive layout
- Strong enterprise visual polish
- No invented exact metrics, public claims, testimonials, or named customer facts unless explicitly provided

---

Each case study card should support:

- Headline

Create the data model so each card can later link to its own detail page.

```ts

  title: string;
  sector: string;
  clientLabel: string;
  summary: string;
  challenge: string;
  approach: string;
  impact: string[];
  services: string[];
  featured?: boolean;

```
